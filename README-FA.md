# اپ اندروید سرِ کوچه

اپ رسمی که سایت https://sarkouche.ir را داخل WebView باز می‌کند.

- پکیج: `ir.sarkouche.app`
- موقعیت مکانی، انتخاب عکس (دوربین/گالری)، کشیدن برای رفرش، دکمه برگشت

## بدون اندروید استودیو — ساخت APK با GitHub

1. یک ریپوی GitHub بساز (مثلاً `sarkouche-android`).
2. همه فایل‌های این پوشه را آپلود/پوش کن.
3. در GitHub: تب **Actions** → workflow **Build APK** → **Run workflow**.
4. بعد از چند دقیقه روی همان run، فایل **sarkouche-debug-apk** را دانلود کن.
5. APK را روی گوشی نصب کن (ممکن است «منابع ناشناس» را فعال کنی).

> برای بازار/مایکت بعداً APK امضاشده (release) لازم است؛ فعلاً debug برای تست کافی است.

## با اندروید استودیو (اختیاری)

Open → این پوشه → Run.

## لوگو

فعلاً آیکون ساده سبز است. بعداً می‌توانی `ic_launcher` را با لوگو اصلی عوض کنی.
